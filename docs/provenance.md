for Browser Agent Blueprint. AI assisted their creation; the maintainer is
responsible for review and release. No vendor internal prompt is represented
as authentic, and no CL4R1T4S prompt text was copied, translated or paraphrased
into these modules.

The public [CL4R1T4S repository](https://github.com/elder-plinius/CL4R1T4S)
was considered as a distribution reference: clear positioning, easily copied
materials and a browsable collection. That reference is not code ancestry,
a vendor endorsement or a source of this project's prompt modules.
