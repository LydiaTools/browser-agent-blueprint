# Contributing

Useful contributions are small modules, reproducible failure cases, browser
adapter mappings and live-model evaluations with explicit versions and limits.
Open an issue with the command, expected result, observed result and environment.
Use synthetic examples. Remove credentials, cookies and private page data.

Do not contribute alleged leaked prompts, proprietary dumps, unverifiable
benchmarks, platform-policy bypasses, fake engagement or copied vendor branding.
Explain provenance for contributed text/code/assets and keep applicable licenses.
Run `npm test` and `npm run metrics`. Browser changes should include the demo
commands and a clearly scoped observation, not a general reliability claim.
The maintainer reviews contributions before merging; no response time is promised.
